# Project context

This is a demo project for a job application to a 3D/BIM software company.

## Stack
- React with Vite
- shadcn/ui (Radix UI based) for components
- Tailwind CSS v4 for styling
- react-three-fiber and drei for the 3D scene

## Goal
Build a small 3D viewer (a cube or simple object) with orbit camera controls,
plus a shadcn/ui panel alongside it that lets the user change something about
the object, like its color.

## Rules
- Use shadcn/ui components wherever possible instead of custom-built UI
- Keep the 3D canvas and the UI panel visually separated but in the same layout
